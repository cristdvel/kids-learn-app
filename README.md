# Kids Learn (app web compilada)

Versión web instalable de una app familiar para aprender jugando (mates, lectura, escritura e inglés). Funciona sin conexión una vez cargada; los datos de cada niño se guardan en el propio aparato.

- Dibujos: [OpenMoji](https://openmoji.org) (CC BY-SA 4.0), ver `fonts/OpenMoji-LICENSE.txt`.
- Reconocimiento de voz sin conexión: [Vosk](https://alphacephei.com/vosk) (Apache 2.0), con los modelos pequeños de español e inglés.
